# Manual da fictícia Nimbus Rewards

A Nimbus Rewards é um programa de fidelidade fictício criado apenas
para o teste E2E principal (RAG-080) — nenhuma relação com nenhum
sistema real do rag-platform.

## Como resgatar pontos

Para resgatar pontos na Nimbus Rewards, o titular precisa acumular ao
menos QUATROCENTOS pontos NimbusCoin e solicitar o resgate pelo código
secreto de ativação GIRASSOL-7. Sem o código GIRASSOL-7, nenhum resgate
é processado, mesmo com saldo suficiente.

## Validade dos pontos

Pontos NimbusCoin expiram 18 meses após serem creditados, contados a
partir da data do crédito, não da data de adesão ao programa.
